RL for reasoning & agents

What is different

No labels — only a scalar reward, often delayed. The agent's own actions choose its data, so it must balance exploring against exploiting.

In Earth observation

Satellite tasking and scheduling, UAV survey paths, adaptive field sampling, irrigation and reservoir control — and RLHF behind the LLMs and agents of Chapters V.6 and V.10.

Turing already proposed rewards and punishments (Part I); Bellman gave the mathematics (dynamic programming), Sutton and Watkins the learning algorithms (TD, Q-learning). Deep networks then turned tables into function approximators: DQN, AlphaGo, and today RL from human feedback, which aligns the LLMs we use for agents. The demos that follow use one toy EO problem: a survey drone that must reach a flooded village while avoiding storm cells.

Markov decision processes — the Bellman equation

MDP \((\mathcal S,\mathcal A,P,R,\gamma)\) · return \(G_t=\sum_{k\ge0}\gamma^k r_{t+k+1}\) · policy \(\pi(a\mid s)\) $$V^*(s)=\max_a\sum_{s'}P(s'\mid s,a)\big[R(s,a,s')+\gamma\,V^*(s')\big]$$ $$V_{k+1}(s)\leftarrow\max_a\sum_{s'}P(s'\mid s,a)\big[R+\gamma V_k(s')\big],\qquad \pi^*(s)=\arg\max_a Q^*(s,a)$$

Planning with a known model

Value iteration applies the Bellman update to every state. It is a \(\gamma\)-contraction, so \(V_k\to V^*\) from any start; values spread outward from the rewards, sweep by sweep.

Q-learning — learn values from experience

$$Q(s,a)\leftarrow Q(s,a)+\alpha\Big[\underbrace{r+\gamma\max_{a'}Q(s',a')}_{\text{TD target}}-Q(s,a)\Big]$$
ε-greedy: random action with probability ε, otherwise \(\arg\max_a Q(s,a)\) · SARSA uses the action actually taken instead of the max

Model-free

No transition model: the drone only sees \((s,a,r,s')\) and bootstraps from its own estimates (temporal-difference learning). Q-learning is off-policy: it learns the greedy policy while behaving ε-greedily.

Exploration matters

With ε = 0 the drone may lock onto the first route that worked. Too much ε and it keeps flying into storms. Learning rate α trades speed for noise.

Multi-armed bandits — explore or exploit?

Regret after \(T\) steps: \(\;R_T=T\mu^*-\sum_{t=1}^{T}\mu_{a_t}\) $$\text{UCB1: }a_t=\arg\max_a\Big[\hat\mu_a+c\sqrt{\tfrac{\ln t}{N_a}}\Big]$$ $$\text{Thompson: }\tilde\mu_a\sim\text{Beta}(1+S_a,\,1+N_a-S_a),\ \ a_t=\arg\max_a\tilde\mu_a$$

RL with one state

Five field sites, each with an unknown chance of detecting an event per visit. Every visit spent learning about a poor site is a lost detection. ε-greedy explores blindly; UCB is optimistic about uncertain sites; Thompson samples from its beliefs.

Bandits are used for adaptive sampling, sensor tasking and A/B testing — and their logic (optimism, posterior sampling) runs inside full RL agents.
Press +1000 and watch the regret curves: ε-greedy grows linearly (it keeps exploring at rate ε forever), UCB1 and Thompson grow roughly logarithmically, the optimal rate (Lai & Robbins). Switch the bar chart between strategies: Thompson concentrates its visits on site D (the best, 0.68) quickly. Tick “true rates” to compare estimates with the truth. Changing ε or c restarts the run.

Lab 3 · Learn to irrigate, learn to task a satellite

# state: (week, root-zone depletion D in 10-mm bins) · action: irrigate 0, 20 or 40 mm
def step(week, D, a, rng):
    rain = rng.choice(RAIN_MM, p=RAIN_P[week])               # stochastic weather
    ks = 1.0 if D <= RAW else max(0.0, (TAW - D) / (TAW - RAW))  # FAO-56 stress coefficient
    D2 = DSTEP * np.round(np.clip(D + ks * ETC[week] - IRR[a] - rain, 0, TAW) / DSTEP)
    reward = YIELD_W[week] * ks - WATER_COST * IRR[a]           # crop response − water cost
    return D2, reward

V, policy = value_iteration(P, R, horizon=20)    # exact: we know the model

Q = np.zeros((20, N_D, 3))                       # model-free: learn from simulated seasons
for episode in range(50_000):
    D = D0
    for week in range(20):
        a = rng.integers(3) if rng.random() < eps else Q[week, b(D)].argmax()
        D2, r = step(week, D, a, rng)
        target = r + (Q[week + 1, b(D2)].max() if week < 19 else 0.0)
        Q[week, b(D), a] += alpha * (target - Q[week, b(D), a])
        D = D2

NumPy only, CPU, ≈ 2 min. The simulator is the hard part of real RL — this one is a toy.
Value iteration needs the transition probabilities, which we have because we wrote the simulator; Q-learning only needs to interact with it. Compare both with the FAO-56 rule of thumb (irrigate when depletion exceeds RAW) and with fixed calendars. The learned policy irrigates less early in the season and protects the sensitive mid-season weeks, where the yield weight is highest. The bandit part is the simplest RL problem: no state, just which of five acquisition windows to request; regret curves show why optimism (UCB) and posterior sampling (Thompson) beat a fixed exploration rate. From tables to networks: deep RL and RLHF

DQN — a CNN replaces the Q-table; replay buffer + target network \(\theta^-\): $$\mathcal{L}(\theta)=\mathbb{E}\Big[\big(r+\gamma\max_{a'}Q_{\theta^-}(s',a')-Q_\theta(s,a)\big)^2\Big]$$
Policy gradient (REINFORCE) — learn \(\pi_\theta\) directly: $$\nabla_\theta J(\theta)=\mathbb{E}_{\pi_\theta}\Big[\sum_t\nabla_\theta\log\pi_\theta(a_t\mid s_t)\,G_t\Big]$$
PPO — stable updates with a clipped ratio \(\rho_t=\pi_\theta(a_t|s_t)/\pi_{\text{old}}(a_t|s_t)\): $$L^{\text{CLIP}}=\mathbb{E}_t\big[\min\big(\rho_t\hat A_t,\ \operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)\hat A_t\big)\big]$$

EO problemState → action → reward
Satellite taskingqueue, clouds → which target next → value of images acquired
UAV surveymap so far → where to fly → area covered per battery
Irrigation controlsoil moisture, ET, forecast → water amount → yield − water cost
Tabular methods do not scale to images or continuous states, so neural networks (Part V) approximate Q or π. DQN learned Atari from pixels; AlphaGo combined policy and value networks with tree search; PPO is the workhorse optimiser. RLHF reuses PPO to fine-tune language models on a learned reward of human preferences, with a KL penalty that keeps the model close to its supervised starting point — this is the alignment step behind the LLMs of Chapter V.6. In EO, RL is still mostly research: rewards are hard to define and simulators are needed to train safely. This slide is the bridge to Part V: once the Q-table becomes a network, everything we know about training networks applies.
