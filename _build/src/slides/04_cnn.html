Three priors that make images learnable

◎

Locality

A pixel is explained by its neighbours: a roof edge, a field boundary, a river bank. Each neuron looks at a small window (3×3).

⧉

Weight sharing

The same filter slides over the whole image. A “bright-line detector” is useful everywhere — so learn it once.

⇄

Equivariance

Shift the input, the feature map shifts the same way. A building is a building in any corner of the tile.

MLP on a 13×64×64 EuroSAT patch with 256 hidden units: \(13\cdot64\cdot64\cdot256 \approx\) 13.6 M weights in the first layer alone.
Conv layer, 64 filters of 3×3 over 13 bands: \(3\cdot3\cdot13\cdot64 =\) 7 488 weights — and it works on any image size.
The numbers make the point: convolution is a massive reduction in parameters by building in the right assumptions about images. 13·64·64 = 53 248 inputs × 256 = 13.6 M.

Convolution in action — filters are feature detectors

input scene
feature map
$$(\mathbf{I}\ast\mathbf{K})_{i,j}=\sum_{c}\sum_{m,n}\mathbf{I}_{c,\,i+m,\,j+n}\,\mathbf{K}_{c,m,n}+b$$

Kernel

Output size: \(\;W_{out}=\left\lfloor\frac{W-K+2P}{S}\right\rfloor+1\)
e.g. 64-px tile, K = 3, P = 1, S = 2 ⇒ 32 px.
In a CNN the kernel values are not hand-picked: they are weights learned by back-prop.
Click Sobel x / y: the road and field boundaries light up — the same edge features that classical remote sensing computed by hand. In a trained CNN the first layer learns filters very much like these, deeper layers combine them into textures and objects.

Receptive field

Each layer widens what a neuron “sees”. Two 3×3 convs see 5×5; with down-sampling a deep neuron covers hundreds of metres on Sentinel-2.

Pooling

Max/average pooling summarise a window: robustness to small shifts, cheaper compute. Global average pooling feeds the classifier.

Normalisation

Batch-norm stabilises training; with multispectral data, normalise inputs per band with dataset statistics.

Resolution matters in EO: a 3×3 kernel is 30 m on Sentinel-2 but 1.5 m on 50-cm imagery. Choose the backbone depth and input size for the size of the objects you want to see.
Highlight the EO-specific consideration: the same network “sees” very different ground areas depending on GSD. For informal settlements (small, dense roofs) you need sub-metre to ~3 m imagery or much deeper context.

Residual block — learn the change, keep an identity highway for gradients:
$$\mathbf{y} = \mathcal{F}(\mathbf{x};\{\mathbf{W}_i\}) + \mathbf{x}$$

Why ResNet matters

\(\partial\mathbf{y}/\partial\mathbf{x} = \partial\mathcal{F}/\partial\mathbf{x} + \mathbf{I}\): the “+I” keeps gradients alive through very deep nets — the same trick lives inside every Transformer block.

ResNet-18/50 remain the most used EO backbones; SSL4EO-S12 provides Sentinel-1/2 pre-trained weights.
Emphasise ResNet and U-Net — they are the two architectures participants will use most in EO practice. Residual connections reappear in Transformers.

Lab 2 · Transfer learning: ImageNet ResNet → EuroSAT

import torch, torch.nn as nn
from torchvision import datasets, transforms, models

tf = transforms.Compose([
    transforms.Resize(224), transforms.RandomHorizontalFlip(),
    transforms.RandomVerticalFlip(), transforms.ToTensor(),
    transforms.Normalize([0.485, 0.456, 0.406],
                         [0.229, 0.224, 0.225])])
ds = datasets.EuroSAT("data", transform=tf, download=True)
train_ds, val_ds = torch.utils.data.random_split(
    ds, [0.8, 0.2], generator=torch.Generator().manual_seed(42))

model = models.resnet18(weights=models.ResNet18_Weights.DEFAULT)
model.fc = nn.Linear(model.fc.in_features, 10)   # new head

# stage 1: freeze backbone, train the head (fast)
for n, p in model.named_parameters():
    p.requires_grad = n.startswith("fc")
opt = torch.optim.AdamW(filter(lambda p: p.requires_grad,
                               model.parameters()), lr=1e-3)
# stage 2: unfreeze all, lr=1e-4, a few more epochs

Why it works

Early ImageNet filters (edges, textures) are generic. Only the head is task-specific. With 27 000 EuroSAT patches, fine-tuning typically reaches high-90s % accuracy — far above the spectral MLP.

Lab 3 · U-Net semantic segmentation

  • Encoder (often a pre-trained ResNet) captures what; decoder recovers where.
  • Skips pass fine edges to the decoder ⇒ crisp field and building boundaries.
  • Loss: cross-entropy + Dice for rare classes; metric: IoU = TP / (TP + FP + FN).
import torch, torch.nn as nn
import segmentation_models_pytorch as smp
from torchgeo.datasets import LandCoverAI
from torch.utils.data import DataLoader

train = LandCoverAI("data", split="train", download=True)
dl = DataLoader(train, batch_size=8, shuffle=True)

# 5 classes: background, building, woodland, water, road
model = smp.Unet("resnet34", encoder_weights="imagenet",
                 in_channels=3, classes=5)
ce, dice = nn.CrossEntropyLoss(), smp.losses.DiceLoss("multiclass")
opt = torch.optim.AdamW(model.parameters(), lr=3e-4)

for batch in dl:
    x = batch["image"].float() / 255.0       # (B,3,512,512)
    y = batch["mask"].long()                 # (B,512,512)
    logits = model(x)                        # (B,5,512,512)
    loss = ce(logits, y) + dice(logits, y)
    opt.zero_grad(); loss.backward(); opt.step()

tp, fp, fn, tn = smp.metrics.get_stats(logits.argmax(1), y,
                     mode="multiclass", num_classes=5)
print("mIoU", smp.metrics.iou_score(tp, fp, fn, tn, reduction="macro"))
U-Net is the default architecture for EO segmentation and the decoder pattern reappears on top of foundation models (UPerNet / U-Net decoders in TerraTorch). LandCover.ai has 25–50 cm aerial orthophotos of Poland; buildings and roads are the hard, small classes.
