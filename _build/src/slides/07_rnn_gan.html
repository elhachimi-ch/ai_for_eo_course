Recurrent networks: a loop with memory

$$\mathbf{h}_t=\tanh\!\left(\mathbf{W}_h\mathbf{h}_{t-1}+\mathbf{W}_x\mathbf{x}_t+\mathbf{b}\right)$$
  • A state \(\mathbf{h}_t\) summarises the past: an NDVI trajectory, a week of weather.
  • BPTT: unroll in time and back-propagate through all steps.
Gradient from step \(T\) back to step \(k\): $$\frac{\partial \mathbf{h}_T}{\partial \mathbf{h}_k}=\prod_{t=k+1}^{T}\frac{\partial \mathbf{h}_t}{\partial \mathbf{h}_{t-1}}$$ If the factors are < 1 the product vanishes, > 1 it explodes. Plain RNNs forget after ~10–20 steps.
Exploding gradients: clip them. Vanishing gradients need a new architecture — the LSTM.
Connect to the backprop slide: the product of Jacobians is the time-axis version of the vanishing-gradient problem. A season of 10-day Sentinel-2 composites is ~36 steps; daily weather over a growing season is 150+ steps.

LSTM: a gated memory cell

$$\begin{aligned} \mathbf{f}_t&=\sigma(\mathbf{W}_f[\mathbf{h}_{t-1},\mathbf{x}_t]+\mathbf{b}_f) &&\text{forget}\\ \mathbf{i}_t&=\sigma(\mathbf{W}_i[\mathbf{h}_{t-1},\mathbf{x}_t]+\mathbf{b}_i) &&\text{input}\\ \tilde{\mathbf{c}}_t&=\tanh(\mathbf{W}_c[\mathbf{h}_{t-1},\mathbf{x}_t]+\mathbf{b}_c) &&\text{candidate}\\ \mathbf{c}_t&=\mathbf{f}_t\odot\mathbf{c}_{t-1}+\mathbf{i}_t\odot\tilde{\mathbf{c}}_t &&\text{cell update}\\ \mathbf{o}_t&=\sigma(\mathbf{W}_o[\mathbf{h}_{t-1},\mathbf{x}_t]+\mathbf{b}_o) &&\text{output}\\ \mathbf{h}_t&=\mathbf{o}_t\odot\tanh(\mathbf{c}_t) \end{aligned}$$

The key line

\(\mathbf{c}_t=\mathbf{f}_t\odot\mathbf{c}_{t-1}+\dots\) is additive. When \(\mathbf{f}_t\approx 1\) information and gradients flow unchanged across many steps — the same “identity highway” idea as ResNet, ten years earlier.

Reading the gates in EO terms

  • Forget: drop the memory of last season after harvest
  • Input: store a rainfall event that will matter for soil moisture
  • Output: expose the memory when the crop starts greening
GRU (2014) merges gates (update, reset) — fewer parameters, often similar accuracy.
Sigmoid gates output values between 0 and 1: they act as soft switches. Make the analogy with irrigation management: the cell state is like the soil water bucket — inputs fill it, the forget gate drains it.

Where time matters in Earth observation

Crop-type mapping

Sentinel-2 time series per parcel → LSTM / temporal attention. Phenology (green-up, peak, harvest) separates wheat from barley better than any single date (BreizhCrops benchmark).

Hydrology

LSTMs trained on hundreds of catchments predict river discharge from meteorological forcings and rival process models (Kratzert et al., 2018).

Nowcasting

ConvLSTM replaces matrix products with convolutions to forecast radar-precipitation fields — space and time.

Evapotranspiration & drought

Forecast FAO-56 reference ETo from temperature, radiation, wind and humidity for irrigation scheduling — Lab 7, with a Marrakech example.

Today, temporal Transformers (Chapter V.5) often replace LSTMs on long, irregular satellite time series — but LSTMs stay strong, light baselines on small data.
Reference ETo is the FAO-56 Penman–Monteith quantity; Open-Meteo provides it computed from ERA5 reanalysis, which makes a quick, reproducible lab. For operational work, compute it from station or ERA5-Land variables yourself.

Evaluate honestly

  • Baselines: persistence (tomorrow = today) and day-of-year climatology
  • RMSE and R² per lead day (1…7)
  • Add sin/cos of day-of-year as inputs
Splitting by time (not randomly) is the temporal equivalent of spatial blocking. A model that cannot beat climatology at lead day 7 has not learned anything useful beyond the seasonal cycle.

GANs: a forger and a detective

Noise zor a condition (SAR)
→
Generator Gmakes a fake image
→
Discriminator Dreal or fake?
$$\min_G\max_D\;\mathbb{E}_{\mathbf{x}\sim p_{\text{data}}}[\log D(\mathbf{x})]+\mathbb{E}_{\mathbf{z}\sim p_z}[\log(1-D(G(\mathbf{z})))]$$

At the equilibrium of this game, \(p_G = p_{\text{data}}\) and \(D=\tfrac12\) everywhere. In practice training is a delicate balance: mode collapse, oscillation, sensitivity to hyper-parameters.

The generative family

ModelIdea
Autoencodercompress → reconstruct (denoising, anomalies)
VAEprobabilistic latent space, smooth sampling
GANadversarial game, sharp images
Diffusionlearn to remove noise step by step
Masked autoencoders (Chapters V.5 and V.7) are the autoencoder idea scaled into foundation-model pre-training.
Keep it intuitive: the generator improves because the discriminator keeps raising the bar. Mention that the autoencoder idea returns at scale as MAE, the pre-training objective of Prithvi and SatMAE.

Image-to-image: pix2pix, CycleGAN, diffusion

pix2pix · paired

$$\mathcal{L}=\mathcal{L}_{cGAN}(G,D)+\lambda\,\lVert y-G(x)\rVert_1$$

U-Net generator + PatchGAN discriminator. λ ≈ 100: L1 keeps colours right, the GAN term adds texture.

CycleGAN · unpaired

$$\lVert F(G(x))-x\rVert_1+\lVert G(F(y))-y\rVert_1$$

Two generators and a cycle-consistency loss: translate without co-registered pairs.

Diffusion · state of the art

$$\mathbb{E}\,\lVert\boldsymbol\epsilon-\boldsymbol\epsilon_\theta(\mathbf{x}_t,t)\rVert^2$$

Learn to predict the added noise; generate by iterative denoising. More stable than GANs, slower to sample.

Lab 8 · pix2pix: Sentinel-1 → Sentinel-2

import torch, torch.nn as nn
import segmentation_models_pytorch as smp

# Generator: U-Net, 2 SAR bands (VV, VH in dB) -> 3 optical bands
G = smp.Unet("resnet34", encoder_weights=None, in_channels=2,
             classes=3, activation="tanh")

class PatchD(nn.Module):           # judges 70x70 patches
    def __init__(self, c_in=2 + 3):
        super().__init__()
        def blk(i, o, norm=True):
            return [nn.Conv2d(i, o, 4, 2, 1)] + \
                   ([nn.InstanceNorm2d(o)] if norm else []) + \
                   [nn.LeakyReLU(0.2)]
        self.net = nn.Sequential(*blk(c_in, 64, False), *blk(64, 128),
                                 *blk(128, 256), nn.Conv2d(256, 1, 4, 1, 1))
    def forward(self, s1, s2):
        return self.net(torch.cat([s1, s2], 1))
D = PatchD()

bce, l1 = nn.BCEWithLogitsLoss(), nn.L1Loss()
optG = torch.optim.Adam(G.parameters(), 2e-4, betas=(0.5, 0.999))
optD = torch.optim.Adam(D.parameters(), 2e-4, betas=(0.5, 0.999))

for s1, s2 in loader:              # co-registered 256x256 chips
    fake = G(s1)
    # 1) discriminator: real -> 1, fake -> 0
    d_real, d_fake = D(s1, s2), D(s1, fake.detach())
    loss_D = 0.5 * (bce(d_real, torch.ones_like(d_real)) +
                    bce(d_fake, torch.zeros_like(d_fake)))
    optD.zero_grad(); loss_D.backward(); optD.step()
    # 2) generator: fool D + stay close to the truth (L1)
    d_fake = D(s1, fake)
    loss_G = bce(d_fake, torch.ones_like(d_fake)) \
             + 100 * l1(fake, s2)
    optG.zero_grad(); loss_G.backward(); optG.step()
