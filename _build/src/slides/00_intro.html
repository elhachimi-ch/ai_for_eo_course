The course follows the history of AI. Part I sets out the four ways a machine can learn; Parts II–IV take the three classical ones in the order they matured — statistical learning from labels, structure without labels, learning from rewards — each with its history, theory, live demos and a lab. Part V is deep learning in chronological chapters, from the first artificial neuron to foundation models and agents. Every part ends with an EO lab; the full, runnable notebooks are in the notebooks/ folder of the site (Colab-ready).

By the end of this course you will be able to…

∑

Explain

how each family — statistical learners (Bayes, trees, ensembles, SVM), clustering and PCA, Q-learning and bandits, MLP, CNN, RNN/LSTM, GAN, Transformer, foundation model, LLM agent — represents data and learns, with the key equation of each.

⌘

Choose

the right architecture for an EO problem: pixels, scenes, segmentation, time series, image translation, multimodal cubes, documents or workflows.

▶

Build

working scikit-learn, PyTorch, TerraTorch, Earth Engine, LangChain and LangGraph pipelines, validated with spatial cross-validation and area estimates.

How to read the slides. Every slide carries a tag: Theory concepts & maths, Practice EO applications and Lab code you can run (notebook link on the slide).
Set expectations: this is a survey course with depth on the core equations and runnable code. Nobody needs to memorise APIs; the goal is to know which tool fits which EO problem and why.
