The Transformer (Vaswani et al., 2017)

$$\operatorname{Attention}(\mathbf{Q},\mathbf{K},\mathbf{V})=\operatorname{softmax}\!\left(\frac{\mathbf{Q}\mathbf{K}^{\top}}{\sqrt{d_k}}\right)\mathbf{V}$$
\(\mathbf{Q}=\mathbf{X}\mathbf{W}_Q,\;\mathbf{K}=\mathbf{X}\mathbf{W}_K,\;\mathbf{V}=\mathbf{X}\mathbf{W}_V\) — every token asks (Q), advertises (K), and shares (V).

Multi-head

\(h\) heads in parallel, each with its own projections, then concatenated: one head may track spectral similarity, another spatial proximity.

Positional encoding

Attention is order-blind, so add position: \(PE_{(p,2i)}=\sin\!\big(p/10000^{2i/d}\big)\). In EO: pixel position, acquisition date, lat/lon.

Block

\(\mathbf{x}\!+\!\mathrm{MHA}(\mathrm{LN}(\mathbf{x}))\), then \(\mathbf{x}\!+\!\mathrm{FFN}(\mathrm{LN}(\mathbf{x}))\) — residuals again.

Cost

Attention is \(O(n^2)\) in the number of tokens: the bottleneck for large images and long time series.

No recurrence, no convolution: every token looks at every other token in one step, so long-range dependencies are one hop away and training parallelises perfectly on GPUs — that is why it scaled. The figure is from the original paper (as used in Chouaib's GeoFM deck).

Beyond text

  • CLIP: align images and captions (contrastive) ⇒ zero-shot classification by text prompt
  • SAM: promptable segmentation (points, boxes) trained on 1 B masks
  • Swin: windowed attention, hierarchical — CNN-like efficiency
A 224×224 image with 16×16 patches ⇒ \(14\times14 = 196\) tokens. Each patch is flattened (\(16\cdot16\cdot C\)) and linearly projected to \(d\) dims.
ViTs have weaker built-in priors than CNNs ⇒ they need more data or pre-training — the opening for self-supervised EO foundation models.
For multispectral data, patch embedding simply sees C = 6, 10 or 13 channels per patch — that is how Prithvi and SatMAE ingest Sentinel/HLS bands.

def attention(Q, K, V, mask=None):
    d = Q.size(-1)
    scores = Q @ K.transpose(-2, -1) / d ** 0.5
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float("-inf"))
    w = scores.softmax(dim=-1)          # (B, n, n)
    return w @ V, w

class PixelTSFormer(nn.Module):
    """Sentinel-2 pixel time series (T dates x C bands) -> class."""
    def __init__(self, n_bands=10, d=64, n_cls=9, max_doy=366):
        super().__init__()
        self.inp = nn.Linear(n_bands, d)
        self.doy = nn.Embedding(max_doy + 1, d)   # date encoding
        layer = nn.TransformerEncoderLayer(
            d, nhead=4, dim_feedforward=128,
            dropout=0.1, batch_first=True)
        self.enc = nn.TransformerEncoder(layer, num_layers=3)
        self.cls = nn.Linear(d, n_cls)

    def forward(self, x, doy, pad_mask=None):
        # x: (B, T, C)  doy: (B, T) day-of-year of each image
        z = self.inp(x) + self.doy(doy)
        z = self.enc(z, src_key_padding_mask=pad_mask)
        return self.cls(z.mean(1))

# irregular dates & cloudy observations: just mask them out
The day-of-year embedding is how temporal transformers deal with irregular acquisitions: positions are real dates, not indices. Cloudy dates are dropped with the padding mask instead of being interpolated — one reason attention works well for optical time series.
